# Parallel Computing Concepts Repository (Java)

This repository serves as a collection of practical code examples and tasks for a Parallel Computing course. Each task is designed to introduce and demonstrate a specific concept related to concurrent programming and parallelism. 

## Tasks:

| **File name**             | **Concept Demonstrated**                       | **Description**                                                                                                                                                                                        | Link                                                                                                   |
| ------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `ThreadGroupingDemo.java` | Thread Grouping & Joining & Exception Handling | Demonstrates basic thread creation, naming, using `t.join()` to wait for a thread's completion, and organizing threads using the **`ThreadGroup`** class, and exception handling using `try{} catch{}` | [Link to file](https://github.com/sara-mohamd/Parallel-Computing/blob/main/01-ThreadGroupingDemo.java) |
